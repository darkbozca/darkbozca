# Oguzhan Bozca

I build software for business workflows and interactive products across web, Android, and Windows. I work on new applications and existing codebases, from defining the first useful release to fixing issues, testing changes, and documenting the handoff.

## What I build

- **Business applications:** Front desk and booking workflows, inventory tracking, staff tools, scheduling, and reporting.
- **Integrations and automation:** API connections, data imports and exports, and tools that replace repetitive spreadsheet and file tasks.
- **Applications and games:** Responsive web interfaces, Android releases, desktop tools, and playable browser experiences.

## How I work

I start by identifying the core workflow and the conditions that make the work ready to use. For larger projects, I split the work into milestones with a working demo at each stage. I document setup and handoff details so the next person can run and maintain the project.
